# Care Budget

Independent demo built by Vinil Polepalli (vinilpolepalli.com), inspired by the problem space Cova (YC S26) works in. Not affiliated with or endorsed by Cova.

Caregiving-finance board for one fictional family coordinating care for a parent: synthetic monthly ledger, illustrative insurance/stipend offsets, net out-of-pocket split across family members with editable shares, a 12-month projection with editable growth, and attention flags with fixed visible thresholds. Every person, expense and benefit is synthetic; the math is fixed-formula illustration, not financial advice.

Static export of a Next.js app. Built with Claude Code.
